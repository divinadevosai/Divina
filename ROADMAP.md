# Roadmap

- **Mac app.** It builds (`npm run build:mac`); it needs signing with an Apple
  Developer ID and notarizing before it can be released.
- **Linux app.** Not built yet.
- **Code-signed Windows installer**, so Windows stops showing the "Unknown
  publisher" warning (see docs/RELEASE.md).
- **Licensed sports and stock feeds** as an option alongside the free ESPN and
  Yahoo Finance ones.

Ideas and bug reports are welcome as GitHub issues.
